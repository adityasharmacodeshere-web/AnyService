# AnyService — submission notes

## Brand and concept

AnyService brings everyday home repairs closer to home by connecting people with local electricians, plumbers, carpenters and appliance service providers. The brand is built around a simple promise: good work should feel neighbourly, dependable and easy to start. A welcoming launch sequence, playful original illustrations, a concise service picker and a clear request flow make the first interaction feel like part of the brand. Midnight blue anchors the identity; repair-shop lime and warm coral add optimism and warmth.

## Technology

HTML, CSS and vanilla JavaScript. The site is static, responsive and runs directly from the local folder, with no package install or build step.

## Assets and credits

The logo, service illustrations, house artwork and small icons were created specifically for this website, with AI-assisted design and implementation. Typography uses local system fonts. No third-party imagery, fonts, icon packs or JavaScript libraries are used. See [ASSETS.md](ASSETS.md) for the asset list.

## Offline presentation

Open `index.html`, select **Press to step inside**, and explore the responsive home page, scroll reveals, the story illustration that drifts with scroll, pointer response and visit picker. The request form validates the details and prepares a pre-addressed email that can be reviewed before sending. Open `privacy.html` for the information-handling notice.
